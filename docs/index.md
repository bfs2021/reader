A local, two-pane reader and editor for a directory of markdown. Pick a file:
it's rendered on the left and editable on the right, and the left side follows
you as you type.

```console
$ reader ~/Documents/notes
```

What it reads is **reader-markdown**: ordinary markdown, as GitHub writes it,
and a few more things for taking notes, reviewing, teaching and presenting.
A file of it still reads as plain text anywhere else.

~ This is an aside, written as a line starting `~`. These pages are
reader-markdown too, saved as HTML with `reader export`.

Each sample in these pages has two tabs: **Source**, what you'd type, and
**Rendered**, what reader makes of it. The pages are saved copies, so what
you click on in reader (a date's calendar, a field to fill in, a puzzle to
play, a recipe's multiplier) shows here as it's written, not as it works.
